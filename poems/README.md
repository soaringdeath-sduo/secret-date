# «Наши признания» — озвучка стихотворений

Для «Операции 28.10». Эта папка — инструкция ведущему для подготовки шести оригинальных коротких аудиопризнаний. Тексты хранятся в [poetry-data.json](../poetry-data.json). Ничего в опубликованном сценарии и датах менять не нужно.

## Согласованный стиль

Все шесть записей должны звучать **одним и тем же мужским голосом**: тёплый, естественный, немного бархатный, без дикторской манеры, с очень лёгкой улыбкой. Это *чтение*, не песня. Лучше оставить тихие паузы между строками и чуть более долгую паузу между строфами. Без преувеличенной сентиментальности.

### Подсказка для генератора с поддержкой voice direction (например, ElevenLabs)

> Естественное русское чтение романтического стихотворения. Низкий тёплый мужской голос, мягкий, слегка бархатный тембр, живые человеческие интонации. Говори спокойно и искренне, как личное признание любимой девушке. Делай короткую паузу после каждой строки и паузу около одной секунды между строфами. Не пой, не используй театральный пафос и не ускоряйся. Слова должны быть отчётливыми, эмоциональность — сдержанной, но искренней. Держи один голос для всей серии.

Если сервис использует настройки вместо текстового описания: русский язык; один и тот же male voice для всех файлов; скорость около 0.90–0.96; нормальная высота голоса. Озвучь только само стихотворение, без заголовка, без вступления «стихотворение номер один» и без фразы «конец записи».

## Быстрый способ (без программирования)

1. Открой [poetry-data.json](../poetry-data.json) и возьми поле \`text\` для нужного дня. Или в режиме ведущего открой завершённый выпуск и нажми «Скопировать текст для ИИ-озвучки».
2. В онлайн-сервисе озвучки выбери *русский мужской* голос. Для художественной подачи важнее живой тембр и ритм, чем глубокая «радио»-басовитость.
3. Сначала проверь файл первого дня. Сохраняй выбранный голос для остальных пяти, чтобы получился единый аудиоальбом.
4. Скачай запись в формате MP3 и переименуй точно как в таблице, например \`poem-day-9.mp3\`.
5. Загрузи файлы в папку \`assets/\` музыкальной ветки/репозитория GitHub. Сайт автоматически обнаружит доступные MP3 и покажет проигрыватель — без дополнительных изменений кода.

Не надо загружать сам ZIP: нужны отдельные MP3, непосредственно в папке \`assets\`. Рекомендация — MP3 128–192 кбит/с, моно или стерео; громкость всех шести желательно выровнять, без резких вступлений.

**Важно:** до загрузки MP3 проигрыватель в интерфейсе Лизы не показывается, чтобы не было неработающих кнопок. Стихотворение при этом можно читать. В режиме ведущего появится подсказка, какой именно файл отсутствует.

Не записывай эти стихи голосом реального актёра или певца без разрешения на использование его голосовой идентичности. Для проекта достаточно лицензионного синтетического голоса. Если когда-нибудь захочется фоновой музыки, используй собственную или музыку с разрешением на такое использование.

## Как работает доступ

- При выборе 14 ноября: доступны выпуски 9–13 ноября — пять стихотворений.
- При выборе 15 ноября: доступны 9–14 ноября — шесть стихотворений.
- Открытие — только после 15-го вопроса своего выпуска. Уже полученные стихи остаются в «Наших признаниях» на том же устройстве.
- Полный тест ведущего хранится отдельно от ответов Лизы.
- GitHub Pages — статический публичный сайт. Скрытие будущих стихотворений в UI не является криптографической защитой от просмотра кода репозитория.
